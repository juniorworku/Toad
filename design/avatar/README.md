# Toad character

[Vector reference](toad.svg). Native animation lives in `android/app/src/main/java/com/toad/companion/ui/Toad.kt`.

A moss-green toad with raised eyes, a pale belly, broad feet, subtle spots and a wide smile. The Nightlight screen layout stays unchanged.

Palette: body `#87A866`, shadow/spots `#5B7547`, belly/eye discs `#DDE8AF`, eyes `#202A36`, glow `#63C6BB`.

Six states: dozing (lowered lids and breathing), listening (open eyes and mic-energy glow), thinking (upward gaze and dots), talking (voice-driven mouth), muted (relaxed lids), peeking (side gaze). Keep blink, eye tracking and existing footprint. Wake phrase: “Hey Toad”; grammar is initially “hey toad” and needs real speech validation. Native visuals have not yet been rendered on a device.
